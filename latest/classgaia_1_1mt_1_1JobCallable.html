Detailed Description

template<typename TArg>
class gaia::mt::JobCallable< TArg >

Move-only type-erased callable owned by a job. Callables of up to InlineSize bytes are stored inline. Larger ones are allocated with mem::AllocHelper. The storage never comes from the process-wide arena allocators (mem::SmallBlockAllocator and friends), so a job callable can be destroyed on whichever thread finishes with the job.

Template Parameters
TArgType passed by const reference to the callable, or void for a callable taking no arguments.

◆ finish()

template<typename TArg >
void gaia::mt::JobCallable< TArg >::finish ( )
inline

Ends the lifetime of the stored callable and everything it captured, but keeps any heap storage until reset() or the destructor releases it. A trivially destructible callable has nothing to end, so it is left untouched and this does not write to the wrapper at all.

Warning
The callable must not be invoked afterwards.
