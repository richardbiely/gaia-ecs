Detailed Description

template<typename It, typename Diff>
class gaia::core::reverse_iterator< It, Diff >

Random-access iterator that traverses an underlying iterator in reverse. The stored iterator denotes the element following the value returned by dereference.

Template Parameters
ItUnderlying random-access iterator type.
DiffSigned type used for iterator distances.
